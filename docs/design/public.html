5 · Public dashboard

FR-26 to FR-32, FR-40, FR-63, FR-113. No sign-in, no admin chrome. Automatic refresh every 5 minutes plus a Refresh button. Times in the viewer’s local time (FR-94).

LoadinggetPublicDashboard (pending)

Skeleton rows; a screen-reader status says “Loading service status…”. Refresh is disabled.

ListgetPublicDashboard 200

Name, status (Healthy or Unhealthy only) and last-check time. No URL, type, failure reason or admin link. The summary line is derived from the rows. Long names wrap; nothing scrolls sideways.

Refresh failednetwork failure / 5xx on refresh

Old rows stay. The banner says when they are from. The automatic 5-minute refresh keeps running.

EmptygetPublicDashboard 200, no services

The public view is on, but no service is set to show on it.

UnavailablegetPublicDashboard 404 public_view_unavailable

The admin has turned the public view off. No refresh button, no automatic refresh.

Too many requestsgetPublicDashboard 429 rate_limited + Retry-After

Retry-After (seconds) counts down; Refresh is disabled until it reaches zero, then the page refreshes once on its own. Old rows stay if there were any.

Same list; summary changes. Shown in the dark theme to check contrast.
