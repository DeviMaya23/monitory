2 · Admin dashboard

FR-9, FR-62, FR-95, FR-26. A flat list of all services ordered by name: no grouping, search, sorting or pagination. Desktop is a dense grid list (a <ul>, not a table) with a visual column header; at 360 px each row becomes a card. Tab order per row: name (opens Edit) → Pause/Resume → Alerts → Edit → Delete. Every icon button has a name such as “Delete API gateway”.

First load after sign-in. Skeleton rows; a screen-reader status announces loading. Add service is available straight away.

ListlistServices 200 + listTargets per service (see question 1)

All four statuses. Status is icon + word + badge shape: solid round (healthy, unhealthy), dashed outline (not checked yet), squared neutral (paused). Unhealthy rows add the failure reason. Paused replaces the status and hides the reason. “Alert delivery failed” links to that service’s alert list. Rows are ordered by name. At 360 px each row becomes a card with labelled actions; nothing scrolls sideways.

Desktop: one line with an ellipsis. The name is the link to Edit, so it can take keyboard focus, and the full name appears in a tooltip on hover and on focus (drawn here). 360 px: the name wraps in full, so no tooltip is needed.

DeletingdeleteService (pending)

Both buttons are disabled; the dialog closes on success and a toast says “Service deleted.” 404 means it was already gone: the dialog closes and the row is removed with the toast “That service was already deleted.”

Pause or resume PartialupdateService (paused)

No confirmation. The row switches to Paused at once and a toast confirms. The same button becomes Resume and keeps focus.

Action failed Partial403 csrf_failed404 not_foundnetwork / 5xx

Row actions (pause, resume, public switch, delete) report errors in a toast; the row keeps its last known state. 404: the row is removed and the toast says it was already deleted. csrf_failed: the toast offers Reload.

Service limit reached PartialcreateService 409 service_limit_reached

The dashboard cannot know the limit beforehand (limits aren’t readable), so Add service stays enabled. The refusal arrives when the form is saved and is shown in the form: see Service form › Service limit reached. Nothing is drawn here (question 3).

Session expired Partialany gated operation 401 unauthenticated

Any 401 (including the 5-minute refresh) leaves for Sign-in, where the “Your session has ended” notice is shown: see Sign-in › Session expired.
